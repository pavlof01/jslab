description

1. [id="ToPrimitive-step-1"] Assert: _input_ is an ECMAScript language value. 1. [id="ToPrimitive-step-2"] If _input_ is an Object, then 1. [id="ToPrimitive-step-2a"] Let _exoticToPrim_ be ? GetMethod(_input_, %Symbol.toPrimitive%). 1. [id="ToPrimitive-step-2b"] If _exoticToPrim_ is not *undefined*, then 1. [id="ToPrimitive-step-2b-i"] If _preferredType_ is not present, let _hint_ be *"default"*. 1. [id="ToPrimitive-step-2b-ii"] Else if _preferredType_ is ~string~, let _hint_ be *"string"*. 1. [id="ToPrimitive-step-2b-iii"] Else, 1. Assert: _preferredType_ is ~number~. 1. Let _hint_ be *"number"*. 1. [id="ToPrimitive-step-2b-iv"] Let _result_ be ? Call(_exoticToPrim_, _input_, « _hint_ »). 1. [id="ToPrimitive-step-2b-v"] If _result_ is not an Object, return _result_. 1. [id="ToPrimitive-step-2b-vi"] Throw a *TypeError* exception. 1. [id="ToPrimitive-step-2c"] If _preferredType_ is not present, let _preferredType_ be ~number~. 1. [id="ToPrimitive-step-2d"] Return ? OrdinaryToPrimitive(_input_, _preferredType_). 1. StringToNumber ( _argument_: a String, )

description

1. [id="StringToNumber-step-1"] Let _literal_ be ParseText(_argument_, |StringNumericLiteral|). 1. [id="StringToNumber-step-2"] If _literal_ is a List of errors, return *NaN*. 1. [id="StringToNumber-step-3"] Return the StringNumericValue of _literal_.

Runtime Semantics: StringNumericValue

description
The syntax-directed operation StringNumericValue takes no arguments and returns a Number.
⚡ This visualizer does not trace StringNumericValue step by step. The result is computed directly as Number(_argument_) and returned as the final value of StringToNumber. The conversion of a StringNumericLiteral to a Number value is similar overall to the determination of the NumericValue of a NumericLiteral, but some of the details are different.

[id="AbstractRelationalComparison-step-1b"] Let _py_ be ? ToPrimitive(_y_, ~number~). 1. [id="AbstractRelationalComparison-step-2"] Else, 1. Let _py_ be ? ToPrimitive(_y_, ~number~). 1. Let _px_ be ? ToPrimitive(_x_, ~number~). 1. [id="AbstractRelationalComparison-step-3"] If _px_ is a String and _py_ is a String, then 1. SameValueNonNumber ( _x_: an ECMAScript language value, _y_: an ECMAScript language value, )

description
Same-value comparison for non-Number operands of the same type.
1. Assert: Type(_x_) is Type(_y_). 1. If _x_ is *undefined* or *null*, return *true*. 1. If _x_ is a BigInt, return BigInt::equal(_x_, _y_). 1. If _x_ is a String, return *true* iff every code unit of _x_ matches _y_. 1. If _x_ is a Boolean, return *true* iff _x_ and _y_ are both *true* or both *false*. 1. Return *true* iff _x_ and _y_ are the same Object/Symbol value.
